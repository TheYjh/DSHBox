# 安装

把需要的 jar 放进游戏实例的 `mods/` 目录即可，无需额外配置。

- 客户端模组（如 Command Keys）只装在客户端。
- 服务端指令模组（如 PokemonKey）装在服务端；单人游玩时客户端也要装。

全部模组要求 **Forge 36 以上**、**Minecraft 1.16.5**。

## 成品目录里都是什么

| 目录 | 里面是什么 | 怎么用 |
|---|---|---|
| `成品/模组/` | 最终模组 jar | **装进游戏的 `mods/` 目录**，这就是你要的东西 |
| `成品/应用/` | 签名 APK | Android 侧的成品，跟 Minecraft 无关，不要放进游戏 |
| `成品/文档/` | 说明文档 | 就是你正在读的这份，加上指令、更新日志和自动生成的模组清单 |

`成品/文档/模组清单.md` **是从 jar 元数据自动生成的**（由 `./deliver` 写出），
不是手工维护的——别去编辑它，改了下次交付就会被覆盖。它列了每个 jar 的 modId、版本与许可证。

`成品/模组/` 里的文件名带中文前缀（如 `[自制-GOD-努力与汗水]pokemonkey-1.1.1.jar`），
那只是便于辨认，安装时不用改名，也不用管前缀。

## 其它文件

- `指令.md`：各模组的游戏内指令。
- `更新日志.md`：已发布过的版本。
- `成品/应用/重铸百科网页版-UI修复/`：网页版界面的修复补丁与说明，与游戏模组无关。
