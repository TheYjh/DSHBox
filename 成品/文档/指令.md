# 指令

## PokemonKey

```
/pokemonkey  <玩家> <1-6> <属性|all> <0-252>   # 设置努力值 EV
/pokemonkey2 <玩家> <1-6> <属性|all> <0-31>    # 设置个体值 IV
```

`<1-6>` 是队伍位置。属性别名：

| 别名 | 含义 |
|---|---|
| `hp` | 血量 |
| `wg` | 物攻 |
| `wf` | 物防 |
| `tg` | 特攻 |
| `tf` | 特防 |
| `speed` | 速度 |
| `all` | 六项全设 |

需要 OP 权限等级 2。

## Command Keys

按键绑定在游戏内设置界面的控制项里配置，绑定后按下按键即执行所配指令。

## Monkey Macros（已移除）

这个模组已从仓库删除（提交 `f70b801`），由 Command Keys 作为进阶替代。已安装旧版的玩家仍可按下述方式使用，但新仓库不再提供它的 jar 与更新。

在 Configured 配置界面里配最多 12 条宏，每条绑定一个按键；按下按键后按顺序执行该宏内的多条指令。
