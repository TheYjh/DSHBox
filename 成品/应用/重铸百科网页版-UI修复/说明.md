# 重铸百科 · 网页版 UI 修复说明

把安卓「UI 修复版」App 的修补内容搬到网页版上。文件夹里有四样东西：

| 文件 | 用途 |
|---|---|
| `重铸百科网页版-1.4.0-UI修复版.zip` | **要发的那一份**。解压即用，已含修复 |
| `ui-fix.css` | 修复样式本体，单独留着便于对照或再次合并 |
| `apply_ui_fix.py` | 从原始网页版资源重新生成一份修复版 |
| `说明.md` | 本文件 |

## 修复了什么

网页版 1.4.0 在窄屏（手机、竖屏平板、半屏窗口）上会出现：

- 招式学习表、能力值计算器横向溢出 —— 页面里给这两张表写死了 `min-width:620px` / `510px`
- 正文列把自己挤成一条竖排 —— `td .prose` 带 `min-width:150px`
- 表格缩略图 70px 宽、90px 高，一个图标占掉整列宽度
- 属性/分类图标和文字并排，列宽不够时把标签挤断行

修复后：表格不再溢出屏幕，字号与内边距按屏宽收敛，图标只留文字标签，计算器输入框随列宽伸缩。

## 和安卓 UI 修复版是什么关系

**这版 App 没有改任何网页文件。** 我们逐字节比对了 `重铸百科-1.4.0-UI修复版.apk` 里的 74904 个网页资源和原始网页版 1.4.0，内容差异为零。修复是 APK 壳（`MainActivity`）在运行时做的两件事：

1. 给每个 `.css` 末尾追加一段补丁样式（`PATCH_CSS`，32 段字符串拼成）；
2. 把 `index.html` 的 viewport 改写成 `<meta name="viewport" content="width=420~720">`，让 WebView 用固定 CSS 宽度把桌面布局整体缩放塞进手机。

网页版没有壳，所以这里把第 1 步落成真实的 `ui-fix.css`，在第 2 步的位置上做了不同选择——见下。

## 唯一与 App 不同的一处

App 把 viewport 锁在 420–720px。这个做法在手机 App 里成立（宽度就那么大），但**网页版要同时在桌面浏览器上打开**：照搬会让整个网站在 1400px 的显示器上被放大成一屏一栏，不可用。

所以：

- 保留原本的 `<meta name="viewport" content="width=device-width, initial-scale=1">`，响应式布局照常工作；
- 把补丁里**压缩布局**的部分收进 `@media (max-width:900px)`；
- 只把纯粹的结构性问题（`min-width:150px` 撑竖排、长串不换行）留在全局。

结果：**桌面端观感与网页版 1.4.0 原版一致，窄屏下得到与 UI 修复版 App 相同的效果。** 900px 是「200px 侧栏 + 620px 表格」刚好放不下的临界点。

## 怎么用

### 直接看

解压 `重铸百科网页版-1.4.0-UI修复版.zip`，双击 `index.html`。离线可用，不需要网络、Java、Python 或 Node。

> 解压后保留 `assets/`、`data/`、`reference/` 等目录，不要只复制 HTML——资料都在这些目录里。

### 已经是网页版 1.4.0，只想加补丁

把 `ui-fix.css` 拷进去，然后在 `index.html` 里 `reading.css` 那行之后加一行：

```html
<link rel="stylesheet" href="reading.css">
<link rel="stylesheet" href="ui-fix.css">
```

顺序不能反：`ui-fix.css` 依赖逐条覆盖 `style.css` / `reading.css` 的同名规则。

### 从原始资源重新生成

```bash
python3 apply_ui_fix.py <原始网页版目录> <输出目录>
```

脚本会拷一份完整资源、放入 `ui-fix.css`、在 `index.html` 插入 `<link>`，并逐条打印做了什么。输出目录必须不存在或为空。449MB、74904 个文件，在机械硬盘上约 2–3 分钟。

## 验证过的

- 输出目录与原始资源逐文件比对：**只有** `index.html` 多一行 `<link>`，外加新增的 `ui-fix.css`，其余 74903 个文件字节不变。
- `ui-fix.css` 括号配平、无解析错误。
- 补丁里用到的选择器（`.table-wrap`、`.pokemon-moves-table`、`.stat-calculator`、`.icon-label`、`.info-pair`、`.detail-tabs`、`.calc-inputs`、`img.structure-img`）在 `app.js` 生成的 DOM 里全部存在，且在 `style.css` / `reading.css` 里确有对应的原始规则可被覆盖。

## 没有改的东西

- 网页版任何原始 CSS / JS / HTML 内容（除了那一行 `<link>`）。
- 安卓 App 本身。
- APK 壳的其余行为（状态栏配色、`setTextZoom(100)`、离线资源拦截、本地 HTTP 服务）——那些属于 App 壳，网页版没有对应位置。
