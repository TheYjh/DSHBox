# 历史只前滚，删除需显式授权

`成品/` 只保留同类产物的最新版，旧版靠 git 历史取回。这条规则只有在历史不被改写的前提下才成立，因此我们决定：**删除一律用 `git rm` 提交，永不用 `filter-repo` 之类的历史重写，永不 force push。**

反方向的对称约束是自动删除：脚本可以检测"哪些旧产物已被取代"，但只有显式传 `--prune` 才真正删除，日常 `./deliver` 绝不删。理由是删除是不可逆方向的自动操作，而重建源码只能靠人工判断——这两件事都不该由一次无人值守的提交决定。

代价是仓库体积只增不减。我们接受这个代价：当前产物总量不到 100KB，而"任何一次误删都能用 `git show` 拿回来"的价值远高于这点空间。

## 范围变更（#26）

模组成品目录 `成品/`、`./deliver` 与 `build-apk.sh` 已于 #26 迁移到 `TheYjh/dsh-mods`，本文关于「旧产物靠 git 历史取回」「自动删除需显式授权」的规则随之一并迁到该仓库的 `BUILD.md`。留在 DSHBox 的、与具体产物目录无关的那条仍然有效：**删除一律用普通前滚提交，永不 `filter-repo`/`filter-branch` 重写历史，永不 force push。**
